# extend-kits 开发文档索引

本目录是 `superpms/extend-kits` composer 包的开发文档入口。这里解释包功能、用法、工作原理、模块边界、扩展方式和开发约定；业务套件自身的业务能力不在这里展开。

## 先读

1. [domains/01-包职责与边界.md](domains/01-包职责与边界.md)
2. [internals/01-启动链与安装投影.md](internals/01-启动链与安装投影.md)
3. [reference/01-kit-json字段参考.md](reference/01-kit-json字段参考.md)

## 按问题读

- 理解启动、目录挂载、autoload 链路：读 [domains/02-生命周期与目录挂载.md](domains/02-生命周期与目录挂载.md) 和 [modules/01-Setup.md](modules/01-Setup.md)。
- 理解根清单、单 kit 清单、extra 状态：读 [domains/03-套件清单与状态.md](domains/03-套件清单与状态.md)。
- 理解平台端和租户端配置入口如何消费这个包：读 [domains/04-管理端与租户端配置.md](domains/04-管理端与租户端配置.md)。
- 理解 `services` 与 action 分发：读 [domains/05-服务声明与动作分发.md](domains/05-服务声明与动作分发.md)。
- 新增一个 kit：读 [how-to/01-新增套件.md](how-to/01-新增套件.md)。
- 接入配置页和安装流程：读 [how-to/02-接入配置页面与安装.md](how-to/02-接入配置页面与安装.md)。
- 声明 provider 或 action：读 [how-to/03-声明服务与动作.md](how-to/03-声明服务与动作.md)。
- 查某个类的方法职责：读 `modules/` 下对应文档。
- 查 server 实际调用点：读 [reference/02-server调用点索引.md](reference/02-server调用点索引.md)。

## 目录结构

- `domains/`：按功能领域解释这个包解决什么问题。
- `modules/`：按包内源码模块解释公开入口和行为边界。
- `how-to/`：面向开发者的操作指南。
- `internals/`：启动、投影、缓存、持久化等内部机制。
- `reference/`：字段、调用点、约定清单。

## 不在这里读

- 业务套件的业务功能说明不写入本目录。
- 一次性排错记录不写入本目录。
- 插件装载文档不写入本目录。
